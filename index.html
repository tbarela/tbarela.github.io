Works

Crypt Walkers

"Crypt Walkers" is my work-in-progress, solo developed indie game. I'm the programmer, artist, and designer. It features Diablo like ARPG gameplay, with the player required to correctly cast spells using W,A,S,D keys, similiar to HellDivers 2. Still early in development, release date TBD.

Tools used: C#, GDScript, Godot, Rider IDE, Git Kraken, Plasticity, Blender, Krita, Inkscape, Tenacity, Gemini AI( Mainly for technical research and discovery. No AI generated assets are currently used in game. )
